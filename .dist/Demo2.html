HTML Lists

HTML has two common list types: ordered lists and unordered lists.

Alphabetic List

Use <ol type="a"> for a, b, c.

  1. Choose a topic
  2. Open your notes
  3. Read the lesson
  4. Write key points
  5. Practice examples
  6. Check your answers
  7. Review your work
  8. Ask a question
  9. Find an answer
  10. Make a summary
  11. Study with a friend
  12. Take a short break
  13. Try a quiz
  14. Fix mistakes
  15. Learn a new word
  16. Write an example
  17. Explain the topic
  18. Set a goal
  19. Finish the lesson
